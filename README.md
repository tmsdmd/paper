أداة بحثية أكاديمية متقدمة تدعم:
- إدارة المشاريع والبحوث والرسائل
- البحث من arXiv و Crossref
- حفظ السجلات في SQLite

- ملاحظات وتحليل وفجوات بحثية
- تصدير PDF عربي/إنجليزي
- واجهة سوداء أنيقة وباللغة العربية والإنجليزية

## التشغيل

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## أبرز المزايا

- بحث علمي من الإنترنت
- قاعدة بيانات محلية منظمة
- إدارة مشاريع بحثية مختلفة
- تراكم بحوثك ورسائلك السابقة
- مقارنة بين الأبحاث بشكل منظم
- تصدير تقارير PDF باللغة العربية أو الإنجليزية

## الهدف

هذا المشروع مصمم ليخدم الباحث أو طالب الماجستير في إدارة البحث العلمي طويل المدى، من جمع المراجع إلى تحليلها ومقارنتها وتلخيصها وتصديرها في شكل تقارير عملية.
